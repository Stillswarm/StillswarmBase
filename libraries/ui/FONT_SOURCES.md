# Bundled fonts

Google Fonts upstream: https://github.com/google/fonts/tree/main/ofl/manrope and https://github.com/google/fonts/tree/main/ofl/inter. SIL OFL notices are packaged in assets/font-licenses.

Static instances generated using fontTools 4.60.2 for Android API 24 compatibility: Manrope wght=600; Inter wght=400/500, opsz=14. All other axes fixed at defaults. No glyph subsetting.
