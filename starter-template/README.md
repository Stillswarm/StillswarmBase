# Starter template

This is a buildable reference application, not yet a project generator. Copy it into a new Android project, change the namespace/application ID/package and branding, and replace project dependencies with published `com.stillswarm.base:foundation-…` coordinates. Copy the root wrapper, catalog, and plugin setup as needed. Do not copy `local.properties`, build output, signing credentials, or IDE state.

The demo and starter have different application IDs and can be installed together.
